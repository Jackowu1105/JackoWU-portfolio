## Research & Discovery

I conducted **stakeholder interviews** with property managers, **user interviews** with 12 residents (ages 28-65), and **competitor analysis** of 6 smart building apps from similar luxury developments in Hong Kong.

### Key Findings

- 78% of users said "opening the app must be faster than using a physical key"
- 65% expressed security concerns about unauthorized access if they lost their phone
- Users strongly preferred a clean interface with 5-6 core features over 15+ rarely-used functions
- 90% of residents preferred a single unified app over installing 3-4 separate facility apps

## Design Process

### Information Architecture

I organized features into 3 categories based on frequency of use: **Access Control** (85% of daily usage — door, mailbox, lift), **Reservations** (12% — clubhouse, facilities), **Visitor Management** (3% — kiosk registration).

### Wireframing & Iteration

**V1** — All features on a single scrolling home screen. Users complained about having to scroll to find commonly-used functions.

**V2** — Bottom tab navigation with "Access Control" as default landing tab. Quick-access widgets for entrance and lift controls. Task completion time reduced from 8 seconds to 3 seconds.

**V3** — Accessibility refinement: increased minimum tap targets to 44x44pt, added haptic feedback, implemented VoiceOver support.

### Key Design Decisions

**QR Code for locker access** — Faster than Bluetooth pairing, works offline, and familiar for Hong Kong users (widely used with Octopus card integration).

**Combined features in one app** — User research showed 90% preferred a unified app over multiple facility apps. Reduced cognitive load, minimized home screen clutter, and provided a cohesive brand experience.

### Usability Testing

**Round 1** — 8 participants: 60% couldn't locate the "Call Lift" feature. Moved "Smart Lift" from buried settings to main Access tab. 100% task success in follow-up.

**Round 2** — 6 participants including 2 elderly residents: Elderly users struggled with small QR code scanning area. Increased viewfinder size by 40%, added real-time visual feedback. Task completion improved from 40% to 95% for senior users.

## Visual Design

### Design System

Built a reusable library with 25+ UI components across 15+ app screens. **Color Palette:** Deep Blue (#1A3A52) for trust and security, Gold (#C9A961) aligned with Henderson Land's luxury branding. **Typography:** System fonts (SF Pro / Roboto) with minimum 16px body text.

### Accessibility

WCAG AA compliance (4.5:1 contrast ratios), large tap targets (44x44pt minimum), VoiceOver/TalkBack support, bilingual support (繁體中文 / English), and high-contrast mode for low-vision users.

## Reflections

This project reinforced the importance of designing for diverse user groups. Balancing the needs of tech-savvy professionals who wanted speed with elderly residents who needed simplicity required careful prioritization and extensive usability testing. Early testing with elderly users is crucial — initial designs failed accessibility requirements, and involving senior residents from the wireframe stage prevented costly late-stage revisions. Offline functionality matters more than expected — QR code generation needed to work without internet in parking garages with poor signal.
