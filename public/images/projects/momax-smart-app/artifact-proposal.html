方案 A · HTML 原生 artifact

方案 B · 重新設計 SVG

保留圖檔方式，但重畫 35 張 SVG：加質感（紙紋、陰影、手寫字體、更有設計感嘅 layout）。改動細，但要逐張重畫。

要改：35 個 SVG 檔重做。工作量：中（但效果仍受 SVG 靜態限制）。

方案 C · 混合

Quote + Persona 用 HTML 卡（最似真 research 輸出嗰兩類），IA/Journey 類保留 SVG 但重畫質感。平衡效果同工作量。
