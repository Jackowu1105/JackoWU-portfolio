01

UX Research

Before drawing a single screen, I treated the legacy app as a problem to understand. ~10 user interviews, ~5 usability tests, analytics drop-off review, competitor teardown.

10 interviews5 usability testsCard-sort ~10 usersPersona: Busy Ben
02

Problem

Setup failed → users never returned. Control felt "broken" past ~2s. Features buried three levels deep. Users think by room, app organised by type.

03

Design Process

Restructured into four primary sections mapped to the user's mental model, validated with card-sorting.

Home
Favourites, one-tap controls
Rooms
Spatial, matches thinking
Automation
Scenes + schedules merged
04

Key Decisions

Bottom tab bar over hamburger (faster task completion). Large device cards over list (clear status, 48px targets). Setup cut from 7 steps to 3.

05

Visual Design

~42 reusable Figma components. MOMAX Blue primary with semantic states, 8-step neutral scale, WCAG AA contrast.

Outcomes

Setup that took minutes became a couple of steps; controls felt instant; buried features one tap away.

而家 vs 新
而家：單欄長 page，冇導航，Highlight 喺最底，要碌晒先知有咩。
新：Sticky TOC 一眼知有咩 section + At-a-Glance 5 秒知重點 + 每 section 有 chips/迷你卡快速消化。
