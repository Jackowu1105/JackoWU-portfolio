## Problem Definition

### User Pain Points

**For participants:** long submission queues, unclear upload steps leading to errors, anxiety about missing deadlines, and confusion about technical requirements (file format, resolution).

**For judges:** inefficient image browsing, lack of filtering and sorting, visual fatigue from reviewing many images, and the need to compare similar entries.

**Business impact:** delayed event schedule, increased staffing costs for on-site support, and risk of participant frustration affecting Canon's brand perception.

## Design Process

### Information Architecture

I mapped the end-to-end workflow for both user groups, identifying the critical touchpoints where friction occurred:

**Participant journey:** Registration → Photo Capture → Upload Initiation → File Selection → Submission Confirmation

**Judge journey:** Login → Image Queue → Review Interface → Scoring/Filtering → Selection Finalisation

### Key Design Decisions

**Simplified, guided upload flow** — Redesigned the submission process into clear, sequential steps with real-time validation (file size, format, resolution checks), progress indicators to reduce anxiety, and inline help text for technical requirements.

**Batch-enabled judging interface** — Grid view with thumbnail previews for quick scanning, filtering and sorting by category or timestamp, and a side-by-side comparison mode for similar entries.

**Mobile-first design** — Participants primarily used smartphones for submission, so I designed for one-handed operation with responsive adaptation to desktop for judges.

## Visual Design

### Design System

A lightweight, clean system on a white base (`#FFFFFF` / `#F3F1F1`) with neutral grey tones (`#767679` / `#A5A6A8`) — keeping the focus on participants' photography rather than the interface chrome, in line with Canon's minimalist brand.

**Typography:** A system sans-serif with a clear hierarchy — large preview thumbnails for judges, generous tap targets for participants.

### Accessibility

WCAG AA color contrast for outdoor visibility, generous touch targets for ease of use under pressure, and clear error messages for submission validation.

## Outcomes & Feedback

The redesigned flow cleared submission queues and cut support requests, and the judging tools let reviewers get through a large volume of images efficiently. The system was reused for later Canon events.

## Reflections

This project taught me the importance of designing for operational efficiency, not just user delight. In high-pressure event contexts, clarity and speed trump visual polish. By deeply understanding both participant and judge workflows, I could create a system that served multiple stakeholders without compromising either experience. Even under tight deadlines, accessibility considerations like outdoor visibility and touch-target sizing proved essential.
