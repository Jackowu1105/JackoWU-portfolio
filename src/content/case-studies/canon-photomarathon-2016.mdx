## Problem Definition

### User Pain Points

**For Participants:** Long submission queues, unclear upload steps leading to errors, anxiety about missing deadlines, confusion about technical requirements (file format, resolution).

**For Judges:** Inefficient image browsing, lack of filtering and sorting capabilities, visual fatigue from reviewing hundreds of images, need to compare similar entries.

**Business Impact:** Delayed event schedule, increased staffing costs for on-site support, risk of participant frustration affecting Canon's brand perception.

## Design Process

### Information Architecture

I mapped the end-to-end workflow for both user groups, identifying critical touchpoints where friction occurred:

**Participant Journey:** Registration → Photo Capture → Upload Initiation → File Selection → Submission Confirmation

**Judge Journey:** Login → Image Queue → Review Interface → Scoring/Filtering → Selection Finalization

### Key Design Decisions

**Simplified, Guided Upload Flow:** Redesigned the submission process into clear, sequential steps with real-time validation (file size, format, resolution checks), progress indicators to reduce anxiety, and inline help text for technical requirements.

**Batch-Enabled Judging Interface:** Grid view with thumbnail previews for quick scanning, filtering and sorting by category or timestamp, and side-by-side comparison mode for similar entries.

**Mobile-First Design:** Participants primarily used smartphones for submission. Designed for one-handed operation with responsive adaptation to desktop for judges.

## Visual Design

Created a lightweight design system ensuring consistency and speeding up development. WCAG AA color contrast for outdoor visibility, minimum 44px touch targets for ease of use under pressure, clear error messages for submission validation.

## Reflections

This project taught me the importance of designing for operational efficiency, not just user delight. In high-pressure event contexts, clarity and speed trump visual polish. By deeply understanding both participant and judge workflows, I was able to create a system that served multiple stakeholders without compromising either experience. Even under tight deadlines, accessibility considerations like outdoor visibility and touch target sizing proved essential.
